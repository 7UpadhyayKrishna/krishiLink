# Fonts

This directory contains the following font files:

- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-Bold.ttf

These files need to be downloaded from Google Fonts before using the application.

## How to download:

1. Visit Google Fonts: https://fonts.google.com/specimen/Poppins
2. Select the Regular, Medium, and Bold weights
3. Download the selected fonts
4. Extract the TTF files and place them in this directory

Alternatively, you can use the `@expo-google-fonts/poppins` package for proper font loading.
